# 💻 Code Camp 2024

## 🚀 Tecnologias e Estrutura

Projeto construído com **HTML5** puro, explorando elementos fundamentais e semânticos da web:

* **Tags Semânticas:** `<header>`, `<section>`, `<div>` e `<footer>` para melhor acessibilidade e estruturação.
* **Tabelas (`<table>`):** Exibição do cronograma do evento (*Event Schedule*) com horários, palestras e salas.
* **Formulários (`<form>`):** Formulário completo de inscrição com:
  * Campos de texto e e-mail
  * Seleção de turno (*Morning / Afternoon*) via `<select>`
  * Caixa de seleção (*checkbox*) com validação obrigatória dos termos
  * Botão de envio (*Submit*)
* **Mídias e Links:** Inclusão de banner com atributos de acessibilidade (`alt`) e links externos para redes sociais.

## 📂 Como visualizar o projeto

1. Basta abrir o arquivo `index.html` em qualquer navegador web (Chrome, Edge, Firefox, etc.).
2. Ou clonar o repositório:
```bash
git clone https://github.com/Aylanunes/camp-code.git
```
